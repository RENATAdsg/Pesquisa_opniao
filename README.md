# 📊 Pesquisa de Satisfação

Script em Python para coleta e contabilização de dados de satisfação de usuários.

## 🎯 Objetivo
Coletar dados de 50 entrevistados (Nome, Idade e Avaliação) e exibir o total de respostas **EXCELENTE** e **RUIM**.

## 🛠️ Tecnologias e Lógica
- `for`: Controle das 50 repetições.
- `while`: Validação de entradas (apenas opções `1`, `2` e `3`).
- `if / elif`: Contabilização dos resultados.

## 📌 Opções
- **1** - EXCELENTE
- **2** - BOM
- **3** - RUIM
